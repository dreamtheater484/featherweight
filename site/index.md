# Featherweight

**A light, fast PDF reader for Windows that also opens and edits Microsoft Word documents, Excel workbooks and
PowerPoint presentations**, with its own engine. One small program, ready in a fraction of a second.

No telemetry, no account, no subscription; the only network access is the update check, which can be turned off.

## What it does

- **PDFs:** read, fill in forms, highlight, add notes, search and print.
- **Word documents** (`.docx`, and older `.doc` and OpenDocument `.odt` files): write and edit with styles, lists,
  tables, pictures, track changes, comments, footnotes and a table of contents; Export PDF.
- **Excel workbooks** (`.xlsx`, `.xls`, `.ods`, `.csv`): formulas, formats, tables, filters, charts and pivot tables.
- **PowerPoint presentations** (`.pptx`, `.ppt`, `.odp`): edit slides, transitions and animations, and present with
  the presenter view.
- **Never damages a file:** saved files open in Office without a repair prompt, and the parts Featherweight doesn't
  edit are kept as they were. Each release goes through tens of thousands of random edits before it ships.

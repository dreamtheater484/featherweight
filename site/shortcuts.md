# Keyboard shortcuts

## Everywhere

| Action | Keys |
|---|---|
| Help | F1 |
| Open, save, save as, print | Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+P |
| Close tab, next and previous tab | Ctrl+W, Ctrl+Tab and Ctrl+Shift+Tab |
| Find, next and previous match | Ctrl+F, Enter and Shift+Enter (or F3 and Shift+F3) |
| Find a command | Alt+Q |
| Full screen, present | F11, F5 (Esc to leave) |

## PDFs

| Action | Keys |
|---|---|
| Copy selected text | Ctrl+C |
| Go to page | Ctrl+G |
| Next and previous page | Page Down and Page Up, Alt+→ and Alt+← |
| First and last page | Home and End |
| Zoom in and out | Ctrl+= and Ctrl+−, Ctrl+scroll |
| Automatic, actual size, fit page, fit width | Ctrl+0, Ctrl+1, Ctrl+2, Ctrl+3 |
| Single page, continuous, two pages | Ctrl+6, Ctrl+7, Ctrl+8 |
| Rotate right and left | Ctrl+Shift+= and Ctrl+Shift+− |
| Night reading | Ctrl+I |
| Save or close a note | Ctrl+Enter, Esc |

## Documents, workbooks and presentations

| Action | Keys |
|---|---|
| New document | Ctrl+N |
| The File page | Alt+F |
| KeyTips on the ribbon, collapse the ribbon | Alt, Ctrl+F1 |
| Bold, italic, underline | Ctrl+B, Ctrl+I, Ctrl+U |
| Undo, redo | Ctrl+Z, Ctrl+Y |
| Find and replace | Ctrl+H |

In Word documents:

| Action | Keys |
|---|---|
| Insert a link | Ctrl+K |
| Paste as plain text | Ctrl+Shift+V |
| Track changes on or off | Ctrl+Shift+E |
| New comment | Ctrl+Alt+M |
| Footnote, endnote | Ctrl+Alt+F, Ctrl+Alt+D |
| Formatting marks | Ctrl+Shift+8 |

In workbooks, **Ctrl+Page Down** and **Ctrl+Page Up** go through the sheets.

The project's website: help, keyboard shortcuts, known issues, privacy and security. Markdown pages with one
layout (`_layouts/default.html`), built by `.github/workflows/pages.yml` with GitHub's Jekyll action and published
on GitHub Pages from main at https://dreamtheater484.github.io/featherweight/.

- The app opens `help/` (F1, Help) and `known-issues/` from there (`src/CrashReport.cpp`); keep those paths.
- `privacy/` is also the Microsoft Store listing's privacy statement.
- The logo and the screenshot are copied from `docs/` when the site is built.
- The network promise is word for word the same everywhere: "No telemetry, no account, no subscription; the only
  network access is the update check, which can be turned off."

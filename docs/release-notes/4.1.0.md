# Featherweight 4.1.0

Featherweight 4.1 is the first stable release with Word documents, Excel workbooks and PowerPoint presentations, next
to the PDF reader you know. It follows the 4.0 beta. It's closer to Word, speaks five languages, edits PDFs' pages,
reads scans and signs, and it's a smaller download.

**Download:** `Featherweight-4.1.0-Setup.exe` (installer, no admin rights needed), `Featherweight-4.1.0-Portable.zip`
(portable), `Featherweight-4.1.0.msi` (per machine, for administrators), and the same for ARM64 (`-arm64`).
`SHA256SUMS.txt` lists every file's checksum.

**Not code-signed yet.** Signing through the SignPath Foundation is being set up. Until then the files are unsigned,
as 4.0's were, so Windows SmartScreen may ask before the first run. Compare the download with `SHA256SUMS.txt`. The
first signed build follows as a 4.1.x with no other change.

## Closer to Word

- Pages break as in Word for 148 of the 152 documents in our test corpus (97 %), and 97.3 % of lines match.
- Typing Enter in the middle of a 300-page document no longer pauses: the worst key is now about 7 ms (4.0: 174 to
  233 ms), and that document is ready 15 % sooner than in 4.0.
- A document with comments opens with the Review pane shown, as Word shows them. Title is one click away in the
  Styles gallery.
- Office's cloud fonts are never read. Documents that use them get a matching font from those Windows installs, so
  the lines still break as in Word.

## Five languages

The interface in English, Dutch, German, French and Spanish. It follows Windows' display language, or the one you
choose in File → Options. Only the chosen language is loaded.

## PDF tools

- **Pages:** thumbnails to reorder, rotate and delete pages; insert pages from another PDF; extract or split pages
  into new files.
- **Scans:** Recognize text reads scanned pages with Windows' own offline OCR and adds an invisible text layer, so
  you can search, select and copy.
- **Signing:** a drawn signature (pen, mouse or a picture), or a certificate signature with a certificate from your
  Windows certificate store. A signed file shows as signed, and a change after signing shows as invalid.
- **Sharing:** Share as PDF and Send as attachment through Windows' share sheet, in all three editors and the PDF tab.

## Installing, updating, deploying

- **ARM64:** native builds for Windows on ARM.
- **For organizations:** an MSI that installs for every user (`msiexec /i Featherweight-4.1.0.msi /qn`), and Group
  Policy templates (`Featherweight-4.1.0-admx.zip`) to turn updates off, pick the update channel and set the
  interface language.
- **Updates:** a beta channel (File → Options → Updates), and "Go back to the previous version" after an update.
  Once Featherweight is signed, the updater installs only an update signed by the same publisher.
- **A smaller download:** forms with scripts (JavaScript and XFA) need a 32 MB script engine that most people never
  use. It's no longer in the download: a PDF that needs it offers it once, and it's downloaded only when you agree.
  Copies that already have it keep it when they update. The installer is about 9.7 MB (4.0's: 19.1 MB).
- **Crashes stay on your PC:** a crash writes a small report in a local folder, and the next start offers to open it
  and a prefilled issue. Nothing is uploaded.

## Trust

- No telemetry, no account, no subscription. The only network access is the update check, which can be turned off,
  and the script engine's download when you agree.
- Every change is scanned by CodeQL, with no open alert of high or critical severity at this release.
- Each release has a software bill of materials (`Featherweight-4.1.0.cdx.json`).
- Reproducible builds: two clean builds of the same source give byte-identical program files
  (`docs/reproducible-builds.md`).
- Before this release, the automated gate (`scripts/f1-gate.ps1`) ran Featherweight's tortures, fidelity checks and
  budgets: 479 documents, 626 workbooks and 179 presentations went through thousands of random edits, and Word, Excel
  and PowerPoint opened every saved copy without a repair, apart from the one workbook whose original Excel repairs
  the same way. 7,557 saved PDFs reopened in PDFium and in Windows' own PDF reader.

## The numbers

- Size: Featherweight.exe 13,667,840 bytes (4.0: 13,167,616), within F1's budget of 1 MB more.
- Launch: the window in 26 ms and ready in 142 ms (4.0, measured back to back on the same PC and 5120×1440 display:
  26.5 and 146.7 ms), memory after launch 24.0 MB (4.0: 24.0 MB). Opening documents, workbooks, presentations and PDFs
  is no more than 5 % slower than 4.0 anywhere, and up to 15 % faster.
- The gate report: `gate-4.1.md`, attached to this release, lists every check of F1's automated gate on this
  release's commit; the checks still waiting for the maintainer's own steps (code signing, the Store, the package
  managers, the scan services, Coverity and a licensed Acrobat) are listed there too.
